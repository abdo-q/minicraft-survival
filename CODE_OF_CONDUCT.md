# Code of Conduct

We are committed to a friendly, harassment-free community for everyone.

**Expected:** be respectful, welcome different viewpoints, give and accept constructive feedback, focus on what is best for the project.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information, or other conduct that would be inappropriate in a professional setting.

Maintainers may remove or edit comments, commits and issues that violate this code, and may ban contributors who do. Report problems by opening an issue or contacting the maintainer through their GitHub profile.

Adapted from the Contributor Covenant, version 2.1.
